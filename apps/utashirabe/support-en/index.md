Thank you for using UtaShirabe.

You can use the in-app feedback feature to report bugs, incorrect song or pitch-range information, duplicate search results, feature requests, and other issues.

## Feedback

An email address is not required when submitting feedback.

Only select “Request a Reply” and enter a reply email address if you need a response. The email address you provide is used only to respond to or clarify that feedback.

## Contact by Email

Support: tsuki03.dev@gmail.com

When contacting support, please include the following information where possible:

- The issue or request
- The song name, if your inquiry concerns a song
- Steps to reproduce the issue
- App version
- iOS version

Do not send sensitive information such as passwords, authentication credentials, or credit card information.

## Account and Data Deletion

UtaShirabe provides a feature that lets you start account deletion from within the App. Deleting an account removes user data associated with that account, including My Songs, singing history, and feedback.

Shared song catalog and pitch-range information is not personal data belonging to a specific user and is not deleted.

For information about how UtaShirabe handles data, please review the Privacy Policy.
